# Who Moved My Heap

Follow `instructions.md` at the project root. It is the one authoritative set of instructions: how
to run the shakers (JMH) and movers (JOL) parts, where every output goes, how to generate the
reports, charts and summaries, and how to build the slides, all at once or one stage at a time.

Start with its sections Q (quick start) and G (ground rules). `HowTo.adoc` is the short guide for
other users; if it disagrees with `instructions.md`, `instructions.md` wins.
