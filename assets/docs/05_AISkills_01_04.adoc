== A skill that suggests the fix

[.track]
Intro · Problem · Definitions · Solutions · [.on]#AI skills# · Wrap-up

[source,markdown]
----
---
name: heap-fix
description: Turn class histogram findings into memory fixes for a JVM
---
1. Run "jps -l", then "jmap -histo <pid>" before and after the workload.
2. For each top grower, suggest the matching fix:
   - Heap near 32 GB: stay below it, so "-XX:+UseCompressedOops" stays on.
   - Object headers: try "-XX:+UseCompactObjectHeaders" on JDK 25.
   - Equal immutable objects: pool them, "String.intern()" or a shared pool.
   - "$$Lambda" and "ReferencePipeline": non-capturing lambdas, plain loops.
   - "HashMap$Node" and boxes: Eclipse Collections, "UnifiedMap", primitive lists.
3. Re-run both histograms and report the bytes saved per class.
----

* Each finding maps to one fix.
* [Measure => Execute => Fix] after every major code change.
* Remember, you don't just check the basement when the house is built, you check periodically.
