== Inside: `ReferencePipeline`

[.track]
[.on]#Appendix#

[.lead]
The internal class behind `Stream<T>`. Primitive versions: `IntPipeline`, `LongPipeline`, `DoublePipeline`.

* `stream()` creates a `Head` stage and a `Spliterator`.
* Each intermediate operation links one new stage (`StatelessOp` or `StatefulOp`).
* The terminal operation creates a `TerminalOp`, chains `Sink` objects and pushes elements through them.
