== A skill to repeat the check

[.track]
Intro · Problem · Definitions · Solutions · [.on]#AI skills# · Wrap-up

[source,markdown]
----
---
name: heap-check
description: Compare class histograms of a running JVM before and after a workload
---
1. Run "jps -l" and pick the pid of the app.
2. Run "jmap -histo <pid> | head -n 27 > before.txt" before the workload.
3. Run "jmap -histo <pid> | head -n 27 > after.txt" after the workload.
4. Subtract per class; list the top 10 by bytes.
5. Flag "HashMap$Node", arrays, "Lambda" and "Stream" "ReferencePipeline" stages.
6. Compare with the last baseline in "heap-baseline.txt".
----

* Run it every release, not only when the basement floods.
