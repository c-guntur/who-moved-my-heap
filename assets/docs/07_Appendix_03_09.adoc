== Eager vs lazy in the JDK

[.track]
[.on]#Appendix#

[cols="1,2,2",options="header"]
|===
| | Eager | Lazy
| When work happens | At each call | At the terminal operation
| In-between results | A new collection per step | None
| Short-circuit | Per step | Across the whole chain
| JDK examples | `anyMatch`, `count`, `findFirst`, `collect`, `removeIf`, `forEach` | `filter`, `map`, `sorted`
|===
