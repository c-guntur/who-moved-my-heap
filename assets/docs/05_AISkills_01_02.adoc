== AI reads JOL and JMH results

[.track]
Intro · Problem · Definitions · Solutions · [.on]#AI skills# · Wrap-up

[.lead]
Raw JMH and JOL output is long; an assistant turns it into a comparison.

* Give it the raw files (JOL outouts as text), not a summary.
* Ask for bytes per call by variant: headers off and on, escape analysis off.
* Ask which numbers are measured and which are derived.
* *Also try*: Prompt to create JMH tests and JOL footprints in code.
