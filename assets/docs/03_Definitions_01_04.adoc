== Escape analysis

[.track]
Intro · Problem · [.on]#Definitions# · Solutions · AI skills · Wrap-up

[.lead]
A C2^1^ JIT^2^ check: when no one outside the method can see a new object, the allocation is removed.

image::diagram-07-escape-analysis.svg[Escape analysis decision,role=diagram]

* Works only on compiled, inlined code, after warm-up.

[.footnote-line]
^1^ C2: the HotSpot server compiler, the optimizing compiler for hot methods (C1 is the fast client compiler). +
^2^ JIT: just-in-time compiler, which turns frequently run bytecode into machine code while the program runs.
