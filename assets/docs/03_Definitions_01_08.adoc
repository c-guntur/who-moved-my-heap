== Immutable Data Object Pooling

[.track]
Intro · Problem · [.on]#Definitions# · Solutions · AI skills · Wrap-up

[.lead]
A pool hands out one shared copy of equal immutable objects instead of many.

[source,java]
----
String s1 = "Heap";                        // 1. literals are interned automatically
String s2 = "Heap";
System.out.println(s1 == s2);              // true: same object in the String pool

String s3 = new String("Heap");            // 2. explicit creation: a separate heap object
System.out.println(s1 == s3);              // false

String s4 = s3.intern();                   // 3. manual interning returns the pooled copy
System.out.println(s1 == s4);              // true: same as s1
----

* JVM setting: `-XX:+UseStringDeduplication` lets the GC share the `byte[]` of equal Strings.
* A pool can be strong (entries stay until removed) or weak (the GC reclaims entries nobody uses).
* Libraries with pools: Guava `Interners`, Apache Commons, Eclipse Collections `Pool`.
