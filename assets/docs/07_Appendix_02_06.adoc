== Escape analysis is not a promise

[.track]
[.on]#Appendix#

[.lead]
With `-XX:-DoEscapeAnalysis` each lambda shape shows what it creates.

[cols="6,2,2",options="header",frame=none,grid=rows]
|===
| `anyMatch`, match at element 500 | EA on | EA off
| JDK `list.stream().anyMatch(...)` | 176 B | 176 B
| EC lazy `asLazy().anySatisfy(...)` | 0 B | 48 B
| EC capturing `Iterate.anySatisfy(...)` | 0 B | 32 B
| EC fat-free `Iterate.anySatisfyWith(...)` | 0 B | 16 B
|===

* The JIT removes allocations only in code it inlines.
* Turning it off is an upper bound, not a typical JVM.
