== AI reads a class histogram

[.track]
Intro · Problem · Definitions · Solutions · [.on]#AI skills# · Wrap-up

[.lead]
Paste two histograms and ask what moved, not what a histogram is.

[source,text]
----
Here are two jmap -histo <pid> outputs, before and after one request.
Which classes grew most, in instances and in bytes?
Look for HashMap$Node, arrays, lambdas and Stream ReferencePipeline stages.
Which code most likely allocated them?
----

* A histogram holds class names and counts; a heap dump holds your data, keep it local.
* Ask for the arithmetic, then check two rows yourself.
* *Also try*: Prompt to run `jps` followed by two executions of `jmap` to produce the above.
