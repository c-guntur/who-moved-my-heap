== Every `HashMap` entry is one more object

[.track]
Intro · [.on]#Problem# · Definitions · Solutions · AI skills · Wrap-up

[.lead]
`HashMap` wraps each entry in a `HashMap$Node`.

* Each node instance is 24 B with *Compact Object Headers (COH)* on, 32 B with COH off.
* A `HashSet` contains a `HashMap`, thus also inherits the problem.
* `Node` plus `Integer` (16 B) ≈ 40 B (or 48 B COH off) of heap per element to hold one `int`.
