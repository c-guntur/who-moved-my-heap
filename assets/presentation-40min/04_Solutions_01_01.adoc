== Measure first: before and after

[.track]
Intro · Problem · Definitions · [.on]#Solutions# · AI skills · Wrap-up

[.lead]
Two class histograms around a workload show what it allocated.

[source,shell]
----
jps -l                                                  # find <pid>
jmap -histo <pid> | grep "Lambda\|ReferencePipeline\|CollectorImpl\|HashMap\|HashSet\|ArrayList\|Integer\|Long\|Double\|Float\|Pair\|String\|\[B" | head -n 27 > before.txt
# ... run the workload ...
jmap -histo <pid> | grep "Lambda\|ReferencePipeline\|CollectorImpl\|HashMap\|HashSet\|ArrayList\|Integer\|Long\|Double\|Float\|Pair\|String\|\[B" | head -n 27 > after.txt
----

* Focus on the big ticket memory occupiers.
* Subtract per class: that is how `prof.HistoProfiler` counts objects per call.
