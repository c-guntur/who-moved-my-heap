== Measure first: before and after

[.track]
Intro · Problem · Definitions · [.on]#Solutions# · AI skills · Wrap-up

[.lead]
Two class histograms around a workload show what it allocated.

[source,shell]
----
jps -l                                                  # find <pid>
jcmd <pid> GC.class_histogram -all > before.txt
# ... run the workload ...
jcmd <pid> GC.class_histogram -all > after.txt
----

* `-all` also counts unreachable objects, so garbage shows up, and no full GC runs first.
* Subtract per class: that is how `prof.HistoProfiler` counts objects per call.

[.notes]
--
⏱ 24:50, stay about 50 s. Solutions: 24:00 to 34:00 (10 min).

`prof.HistoProfiler` (src/main/java/prof) is a JMH profiler that takes a histogram before and after each iteration.
It writes the jcmd output to a temp file because reading it through a pipe can deadlock on JDK 25.
