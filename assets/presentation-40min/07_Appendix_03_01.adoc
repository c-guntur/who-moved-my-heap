== What is a "dollar" class?

[.track]
[.on]#Appendix#

[.lead]
An anonymous class is declared and created in one expression, without a name.

* `javac` still names it: `Outer$1`, `Outer$2`, ...
* Each one gets its own `Outer$1.class` file.
* Named inner and local classes use `$` names too.
