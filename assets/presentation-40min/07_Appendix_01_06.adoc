== Adding JOL to a project

[.track]
[.on]#Appendix#

[source,xml]
----
<dependency>
    <groupId>org.openjdk.jol</groupId>
    <artifactId>jol-core</artifactId>
    <version>0.17</version>
</dependency>
----

[source,shell]
----
java -XX:+EnableDynamicAgentLoading -Djdk.attach.allowAttachSelf=true ...   # let JOL attach to its own JVM
java -jar jol-cli.jar internals java.util.HashMap                            # no code: the command line tool
----

* `jol-cli` is built from the openjdk/jol repository; it also has `footprint` and `heapdump-*` modes.
* jol-samples in the same repository walk through headers, alignment, arrays and more.
