== What is a compact object header?

[.track]
[.on]#Appendix#

[.lead]
The object header shrinks from 12 bytes to one 8-byte word.

* A header holds the mark word (hash, lock, GC state) and a class pointer.
* Product feature in JDK 25 (JEP 519); experimental in JDK 24 (JEP 450).
* Off by default: `-XX:+UseCompactObjectHeaders`.
