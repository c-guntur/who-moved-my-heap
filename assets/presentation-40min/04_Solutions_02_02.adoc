== Enabling compact object headers

[.track]
Intro · Problem · Definitions · [.on]#Solutions# · AI skills · Wrap-up

[source,shell]
----
java -XX:+UseCompactObjectHeaders -jar app.jar
jcmd <pid> VM.flags -all | grep UseCompactObjectHeaders     # check that it is on
----

[cols="6,2,2,2",options="header",frame=none,grid=rows]
|===
| Retained size | Off | On | Saved
| `HashMap<Integer, Integer>`, 1 M entries | 56.4 MB | 48.4 MB | 14%
| `ArrayList<Integer>`, 1 M, presized | 20.0 MB | 20.0 MB | 0%
| `Stream.filter().map().mapToLong()` | 304 B | 272 B | 11%
|===

* One flag, no code change: it shrinks nodes, not boxes.
