== JOL with compact object headers

[.track]
Intro · Problem · Definitions · [.on]#Solutions# · AI skills · Wrap-up

[cols="5,3,6,3",options="header",frame=none,grid=rows]
|===
| `HashMap$Node` ^| Header ^| Fields ^| Size
| Without CompactObjectHeaders ^| 12 B ^| hash, key, value, next: 16 B ^| 32 B (4 B padding)
|  With CompactObjectHeaders ^| 8 B ^| the same 16 B ^| 24 B
|===

* Run the same JOL code with the flag off and on, and compare the sizes.
* The 4 B saved, only counts when the total drops below the next 8 B boundary.
* Note that Compact Object Headers are available from Java 25, but are not on by default.
* You can turn on Compact Object Headers with a CLI flag `-XX:+UseCompactObjectHeaders`.
* Compact Object Headers are now on by default from Java 27.
