== JOL: one `Integer`, compact headers on

[.track]
[.on]#Appendix#

[.lead]
With `-XX:+UseCompactObjectHeaders` the class pointer moves into the 8 B mark word.

[source,text]
----
java.lang.Integer object internals:
OFF  SZ   TYPE DESCRIPTION               VALUE
  0   8        (object header: mark)     0x001ac00000000001 (Lilliput)
  8   4    int Integer.value             500
 12   4        (object alignment gap)
Instance size: 16 bytes
Space losses: 0 bytes internal + 4 bytes external = 4 bytes total
----

* The header shrinks from 12 B to 8 B, but the object still rounds up to 16 B.
* The 4 B saved becomes an alignment gap: a box is a box.

[.notes]
--
Same code as the Intro JOL slide, jol-core 0.17 on JDK 25. "Lilliput" is the OpenJDK project behind compact
object headers (JEP 450 in JDK 24, JEP 519 in JDK 25). Objects whose size crosses an 8 B boundary do shrink:
`HashMap$Node` goes from 32 B to 24 B.
--
