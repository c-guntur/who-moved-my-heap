== Fat-free (non-capturing) lambdas

[.track]
[.on]#Appendix#

[.lead]
Uses only its own parameters, constants and static members.

[source,java]
----
boolean hasMatch(List<Integer> list, Integer target)
{
    return Iterate.anySatisfyWith(list, Object::equals, target);  // one shared instance
}
----

* One instance is created and then reused on every call.
* Extra values travel as arguments (the `*With` methods).
