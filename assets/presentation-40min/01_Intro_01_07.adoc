== JOL: how big is one object?

[.track]
[.on]#Intro# · Problem · Definitions · Solutions · AI skills · Wrap-up

[.lead]
Java Object Layout (JOL) is a small OpenJDK library that shows the header, fields, padding and size of real objects.

[source,java]
----
System.out.println(ClassLayout.parseInstance(Integer.valueOf(500)).toPrintable());
----

[source,text]
----
OFF  SZ   TYPE DESCRIPTION               VALUE
  0   8        (object header: mark)     0x0000000000000001 (non-biasable; age: 0)
  8   4        (object header: class)    0x0019e5d0
 12   4    int Integer.value             500
Instance size: 16 bytes
----

* A library, not a JDK tool: add `org.openjdk.jol:jol-core` to the build.

[.notes]
--
⏱ 05:15, stay about 35 s. Intro: 02:00 to 07:00 (5 min).

Real output of jol-core 0.17 on JDK 25 with `-XX:-UseCompactObjectHeaders`: a 12 B header and a 4 B `int`.
JOL comes back in the solutions (demo 2, headers off and on). The appendix has the same `Integer` with
compact headers on, the footprint of a small list, and how to add JOL to a project.
