== Boxing is a big cost

[.track]
Intro · [.on]#Problem# · Definitions · Solutions · AI skills · Wrap-up

[.lead]
An `Integer` takes 16 B to hold a 4 B `int`, plus a 4 B reference to it.

.1,000,000 elements, compact headers on: retained size (per element)
[caption=,cols="2,3,3,3",options="header",frame=none,grid=rows]
|===
| | JDK Boxed | EC Boxed | EC Primitive
| List | 20.0 MB (20 B) | 20.0 MB (20 B) | 4.0 MB (4 B)
| Set | 48.4 MB (48 B) | 24.4 MB (24 B) | 8.4 MB (8 B)
| Map | 48.4 MB (48 B) | 32.8 MB (32 B) | 16.8 MB (16 B)
|===

[.footnote-line]
*JDK Boxed:* `ArrayList<Integer>` (presized), `HashSet<Integer>`, `HashMap<Integer, Integer>`. +
*EC Boxed:* `FastList<Integer>` (presized), `UnifiedSet<Integer>`, `UnifiedMap<Integer, Integer>`. +
*EC Primitive:* `IntArrayList`, `IntHashSet`, `IntIntHashMap`, no `Integer` boxes.
