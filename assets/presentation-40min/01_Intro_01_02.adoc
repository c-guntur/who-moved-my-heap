== `jps`: which JVM is that?

[.track]
[.on]#Intro# · Problem · Definitions · Solutions · AI skills · Wrap-up

[.lead]
`jps` lists the running Java processes of the current user, so you can find the pid the other tools need.

[source,text]
----
$ jps -l
674  Sleep.java
2310 org.apache.maven.wrapper.MavenWrapperMain
2488 jdk.jcmd/sun.tools.jps.Jps
----

* Each line is a pid and a main class or JAR.
* Adding a `-l` prints the full name.
* `-v` adds the JVM flags, which can show if the CompactObjectHeaders flag is turned on.
