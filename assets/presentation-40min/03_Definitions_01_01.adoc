== Compressed OOPs (Ordinary Object Pointer)s

[.track]
Intro · Problem · [.on]#Definitions# · Solutions · AI skills · Wrap-up

[.lead]
For heaps under 32 GB, Compressed OOPs managed most pointers as 32-bit object offsets from the 64-bit Java heap base address, for upto 4 billion objects.

image::diagram-03-compressed-oops.svg[8-byte vs 4-byte references,role=diagram]

* Every reference field and `Object[]` slot shrinks from 8 to 4 bytes.
* On by default since Java 6u23 (default on flag: `-XX:+UseCompressedOops` ).
