== Object pooling

[.track]
Intro · Problem · [.on]#Definitions# · Solutions · AI skills · Wrap-up

[.lead]
A pool hands out the same objects again instead of allocating new ones.

image::diagram-02-integer-cache.svg[Integer cache from -128 to 127,role=diagram]

* The JDK pools small ``Integer``s: autoboxing calls `Integer.valueOf(int)`.
* -128 to 127 come from the cache; any other value is a new 16 B object.
