== A skill to repeat the check

[.track]
Intro · Problem · Definitions · Solutions · [.on]#AI skills# · Wrap-up

[source,markdown]
----
---
name: heap-check
description: Compare class histograms of a running JVM before and after a workload
---
1. Run `jps -l` and pick the pid of the app.
2. Run `jcmd <pid> GC.class_histogram -all` before and after the workload.
3. Subtract per class; list the top 10 by bytes.
4. Flag boxes, `HashMap$Node`, `Object[]` and `$$Lambda` classes.
5. Compare with the last baseline in `heap-baseline.txt`.
----

* Run it every release, not only when the basement floods.
