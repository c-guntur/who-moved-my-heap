== "Dollar" classes

[.track]
Intro · Problem · [.on]#Definitions# · Solutions · AI skills · Wrap-up

[.lead]
An anonymous class has no name in the code; `javac` names it `Outer$1`.

[cols="1,1",options="noheader",frame=none,grid=none,role=code-grid]
|===
a|
[source,java]
----
public class Shaker
{
    boolean hasMatch(List<Integer> list, Integer target)
    {
        return list.stream().anyMatch(new Predicate<Integer>()  // Shaker$1
        {
            @Override
            public boolean test(Integer each)
            {
                return each.equals(target);
            }
        });
    }
}
----
a|
[source,text]
----
$ javap -p Shaker 'Shaker$1'
public class Shaker {
  public Shaker();
  boolean hasMatch(java.util.List<java.lang.Integer>,
                   java.lang.Integer);
}
class Shaker$1 implements java.util.function.Predicate<java.lang.Integer> {
  final java.lang.Integer val$target;
  Shaker$1();
  public boolean test(java.lang.Integer);
  public boolean test(java.lang.Object);
}
----
|===

* A new instance on every evaluation, even when nothing is captured.
* Captured variables become fields: `val$target`.
