== Reading a class histogram

[.track]
[.on]#Intro# · Problem · Definitions · Solutions · AI skills · Wrap-up

[source,text]
----
 num     #instances         #bytes  class name (module)
-------------------------------------------------------
   1:         15430         698576  [B (java.base@25.0.4.1)
   2:          3302         399272  java.lang.Class (java.base@25.0.4.1)
   3:         15273         366552  java.lang.String (java.base@25.0.4.1)
----

* `[B` on the first line is a `byte[]` - a String-backed array.
* `#bytes` divided by `#instances` is the average object size.
* Comparisons between two timed histograms for a workload, can show the garbage created.
