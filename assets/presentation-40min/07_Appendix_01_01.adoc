== `jcmd` commands for the heap

[.track]
[.on]#Appendix#

[cols="5,9",options="header",frame=none,grid=rows]
|===
| Command | Shows
| `GC.class_histogram` | Instances and bytes per class
| `GC.heap_info` | Heap regions: total, committed and used
| `GC.heap_dump <file>` | HPROF dump for a heap analyzer
| `GC.run` | Requests a full GC
| `VM.flags` | The JVM flags in effect
| `VM.native_memory` | Native memory by area (needs `-XX:NativeMemoryTracking`)
| `Thread.print` | Thread dump
|===
