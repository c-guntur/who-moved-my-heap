== Taking the histograms

[.track]
[.on]#Appendix#

[.lead]
Two everyday JVMs on a developer laptop, and what they hold.

[source,shell]
----
jps -l                          # find the pids
jmap -histo <pid> | head -15    # IntelliJ IDEA
jmap -histo <pid> | head -15    # SonarQube for IDE
----

* Without `:live` the histogram also counts garbage not yet collected.
* Look for `Integer`, `HashMap$Node`, `Object[]` and `$$Lambda` near the top.

[.notes]
--
IntelliJ IDEA shows in `jps -l` as `com.intellij.idea.Main`. Run `jmap` as the same OS user as the process.
`jmap -histo:live` forces a full GC first and shows the baseline only; plain `-histo` shows baseline plus whatever garbage is still there.
--
