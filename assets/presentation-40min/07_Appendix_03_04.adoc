== What is a compressed OOP?

[.track]
[.on]#Appendix#

[.lead]
A 4-byte offset that HotSpot stores instead of an 8-byte reference.

* OOP = ordinary object pointer: a reference to a Java object.
* The offset is scaled by the 8-byte object alignment.
* On by default for heaps under 32 GB (`-XX:+UseCompressedOops`).
