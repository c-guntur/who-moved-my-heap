== Lambdas: capturing vs fat-free

[.track]
Intro · Problem · [.on]#Definitions# · Solutions · AI skills · Wrap-up

[.lead]
A capturing lambda holds values from its scope; a fat-free one uses only its parameters.

image::diagram-06-lambdas.svg[Capturing vs fat-free lambda instances,role=diagram]

* Fat-free: one instance, created once and reused on every call.
* Capturing: a new object that holds the captured values, per evaluation.

[.notes]
--
⏱ 21:50, stay about 70 s. Definitions: 15:00 to 24:00 (9 min).

With escape analysis off, capturing `Iterate.anySatisfy` leaves 16 to 32 B per call; fat-free `anySatisfyWith`
0 to 16 B. The JLS allows either a new or an existing instance (15.27.4); reusing non-capturing
instances is HotSpot behaviour.
