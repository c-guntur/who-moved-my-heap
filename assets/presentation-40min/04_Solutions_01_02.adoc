== JOL: the layout of one object

[.track]
Intro · Problem · Definitions · [.on]#Solutions# · AI skills · Wrap-up

[.lead]
Java Object Layout (JOL) reports how the JVM lays an object out: header, fields, padding and size.

[source,java]
----
import org.openjdk.jol.info.ClassLayout;
import org.openjdk.jol.info.GraphLayout;

System.out.println(ClassLayout.parseClass(String.class).toPrintable());

long bytes = GraphLayout.parseInstance(list).totalSize();   // the object and all it references
----

* `ClassLayout` shows one object; `GraphLayout` adds up everything reachable from it.
* JOL is an OpenJDK project, added as a library; it is not part of the JDK.
