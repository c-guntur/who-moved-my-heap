== Object pooling: de-duplicate immutable objects

[.track]
Intro · Problem · Definitions · [.on]#Solutions# · AI skills · Wrap-up

[.lead]
Share one copy of equal immutable objects instead of allocating many.

* Integer cache: `Integer.valueOf` reuses -128 to 127. `-XX:AutoBoxCacheMax=<n>` raises the upper bound.
* String interning: `String.intern()`. `-XX:+UseStringDeduplication` shares the `byte[]` of equal Strings.
* Object interning: keep your own pool of immutable values, strong or weak.
* Libraries with pools: Guava `Interners`, Apache Commons, Eclipse Collections `Pool`.
