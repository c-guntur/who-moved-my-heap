== `jps`: which JVM is that?

[.lead]
`jps` lists the running Java processes of the current user, so you can find the pid the other tools need.

[source,text]
----
$ jps -l
674  Sleep.java
2310 org.apache.maven.wrapper.MavenWrapperMain
2488 jdk.jcmd/sun.tools.jps.Jps
----

* Each line is a pid and a main class or JAR; `-l` prints the full name.
* `-v` adds the JVM flags, which shows whether compact object headers are on.

[.notes]
--
Run `jps -v` or `jcmd` and look for `-XX:+UseCompactObjectHeaders`. A forked benchmark JVM or surefire
test JVM appears here while it runs, so you can attach `jmap`, `jcmd` or `jstat` to it.
--
