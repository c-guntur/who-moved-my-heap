== `jcmd`: one tool, many commands

[.lead]
`jcmd` sends a diagnostic command to a running JVM; it covers most of what `jmap` and `jinfo` did.

[source,shell]
----
jcmd                              # list the running JVMs and their pids
jcmd <pid> help                   # list the commands that JVM understands
jcmd <pid> GC.class_histogram     # the same histogram as jmap -histo:live
jcmd <pid> GC.class_histogram -all    # includes unreachable objects, no full GC
jcmd <pid> VM.flags               # flags in effect, e.g. +UseCompactObjectHeaders
----

* `-all` counts garbage as well, so one call before and one after shows the allocation.
* `VM.flags` proves whether compact object headers were really on.

[.notes]
--
Run `jcmd` from the same JDK as the target JVM. HistoProfiler writes the jcmd output to a temp file
because reading it through a pipe can deadlock on JDK 25.
--
