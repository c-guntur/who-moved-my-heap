== Capturing vs fat-free

image::diagram-06-lambdas.svg[Capturing vs fat-free lambda instances,role=diagram]

* With escape analysis off, only the arguments remain (here the `Integer` box).

[.notes]
--
With escape analysis off, capturing Iterate.anySatisfy leaves 16 to 32 B per call; fat-free anySatisfyWith
0 to 16 B. The JLS allows either a new or an existing instance (15.27.4); reusing non-capturing
instances is HotSpot behaviour.
--
