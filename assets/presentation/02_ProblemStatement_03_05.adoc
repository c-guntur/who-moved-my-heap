== A stream is an object graph before it runs

[.lead]
An unevaluated pipeline already holds objects, and every operation adds a stage.

[cols="5,2,2",options="header",frame=none,grid=rows]
|===
| Pipeline on an empty list, compact headers on | JDK `Stream` | EC `LazyIterable`
| start: `stream()` / `asLazy()` | 80 B | 16 B
| + `filter` / `select` | 144 B | 24 B
| + `map` / `collect` | 144 B | 24 B
| + `distinct` | 128 B | 16 B
| 3 steps: filter, map, mapToLong | 272 B | 96 B
|===

[.notes]
--
JOL sizes of the pipeline minus the list, movers run 20261015-1503. Each JDK operation adds a stage of 48 to 72 B.
These are sizes, not allocations per call: the next section measures what each call really allocates.
--
