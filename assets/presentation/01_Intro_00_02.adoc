== Agenda

[.lead]
Five tools, from finding a running JVM to the exact layout of one object.

[cols="^1,3,10",options="header",frame=none,grid=rows]
|===
| # | Tool | In one line
| 01 | xref:01_Intro_01_01.adoc[jmap] | Class histogram and heap dump of a running JVM
| 02 | xref:01_Intro_02_01.adoc[jcmd] | One command for most diagnostics, including the histogram
| 03 | xref:01_Intro_03_01.adoc[jps] | Finds the pid of every running JVM
| 04 | xref:01_Intro_04_01.adoc[jstat] | GC and heap counters sampled over time
| 05 | xref:01_Intro_05_01.adoc[JOL] | Header, fields and padding of one object
|===

[.notes]
--
`jps` finds the pid that `jmap`, `jcmd` and `jstat` need. `jstack` (thread dumps) is not covered: threads are not what this talk is about.
--
