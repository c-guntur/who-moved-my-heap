== Capturing (stateful) lambdas

[.lead]
Uses a local, a parameter or `this` from the enclosing scope.

[source,java]
----
boolean hasMatch(List<Integer> list, Integer target)
{
    return list.stream().anyMatch(each -> each.equals(target));  // new object per call
}
----

* Each evaluation creates a new object that holds the captured values.
* Captured locals must be effectively final.
