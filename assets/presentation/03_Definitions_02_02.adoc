== What is object pooling?

[.lead]
A pool keeps objects and hands them out again instead of allocating new ones.

* Callers return an object to the pool when they are done.
* *Worth it* for costly or limited resources: threads, connections, direct buffers.
* *Rarely worth it* for small, short-lived objects:
** young-generation allocation is cheap;
** pooled objects live long and need locking.
