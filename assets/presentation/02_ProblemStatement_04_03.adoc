== Garbage you cannot read from the code

[.lead]
The same line of code leaves different garbage under different conditions.

* `Integer.valueOf(1)` is cached; `Integer.valueOf(500)` costs 16 B per call.
* Escape analysis removes every EC object, and none of the stream's.
* Compact headers save 16 to 24 B per call; the objects stay.
* `anyMatch(p)` is 40 B cheaper than `filter(p).findFirst()`.

[.notes]
--
Escape analysis: JDK bytes per call are identical with `-XX:-DoEscapeAnalysis`. Why it gives up on the pipeline
(linked objects passed through interface calls) is inferred, not confirmed with JIT logs.
Library details matter too: in EC 13.0.0, `ImmutableList.anySatisfyWith`, `countWith` and `detectWithIfNone`
go through `Predicates.bind` and allocate a wrapper per call when escape analysis is off.
--
