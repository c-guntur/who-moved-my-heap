== Fat-free lambdas leave less behind

[source,java]
----
// capturing: a new lambda on every call, holding the value
Iterate.anySatisfy(list, Integer.valueOf(test)::equals);

// fat-free: one constant lambda, the value is a parameter
Iterate.anySatisfyWith(list, Integer::equals, test);

// JDK stream: the pipeline is built whatever the lambda
list.stream().anyMatch(Integer.valueOf(test)::equals);
----

* Escape analysis off: 32 B capturing, 16 B fat-free, 176 B stream.
* Less garbage per call keeps the headroom free for the next spike.

[.notes]
--
The 16 B of the fat-free call is the `Integer` box of `test`, not the lambda. With escape analysis on, both EC calls are 0 B.
The stream has no `*With` form, so even a non-capturing predicate would still leave its pipeline behind.
--
