== `jmap`: what is on the heap?

[.lead]
`jmap` attaches to a running JVM and prints its objects, class by class.

[source,shell]
----
jmap -histo:live <pid>                       # reachable objects only (runs a full GC first)
jmap -histo <pid>                            # every object, garbage included
jmap -dump:live,format=b,file=heap.hprof <pid>   # full heap dump for an analyzer
----

* A histogram is cheap and small; a dump holds every object and field value.
* `:live` hides garbage, which is exactly what allocation tuning needs to see.

[.notes]
--
HistoProfiler (shakers) wants the garbage, so it never uses `:live`; see the jcmd slides.
--
