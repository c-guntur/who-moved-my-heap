== Baseline, churn and a spike

image::diagram-problem-01-baseline-volatile.svg[Heap used over time: a baseline, a sawtooth of garbage and a spike,role=diagram]

* Headroom is what is left above the baseline for garbage.
* A spike multiplies the garbage rate; the baseline stays where it was.

[.notes]
--
An illustration, not a measurement: the shape a GC log shows when a steady live set carries
young-generation churn. A bigger baseline or more garbage per call both eat the same headroom.
--
