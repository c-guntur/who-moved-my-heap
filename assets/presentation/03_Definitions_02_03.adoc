== The JDK's own pool: the `Integer` cache

image::diagram-02-integer-cache.svg[Integer cache from -128 to 127,role=diagram]

* Autoboxing calls `Integer.valueOf(int)`.
* -128 to 127 come from the cache; any other value is a new 16 B object.

[.notes]
--
This is why the shakers benchmarks show an extra 16 B Integer box at match positions 500 and 1000,
but not at position 1.
--
