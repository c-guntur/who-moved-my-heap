== A pipeline in code

[source,java]
----
boolean found = list.stream()                     // source
                    .filter(each -> each > 500)   // intermediate (lazy)
                    .findFirst()                  // terminal (eager)
                    .isPresent();
----

* Every call builds a new pipeline of objects.
* Nothing runs until `findFirst()`.
