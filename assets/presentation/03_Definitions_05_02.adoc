== What is a stream?

[.lead]
A sequence of elements processed by a pipeline: a source, intermediate operations, one terminal operation.

* Intermediate operations (`filter`, `map`) are *lazy*: they only record work.
* The terminal operation (`anyMatch`, `count`, `findFirst`) is *eager*: it runs the pipeline.
* Short-circuiting terminals stop at the first match.
* A stream can be used only once.
