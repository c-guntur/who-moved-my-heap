== Every `HashMap` entry is one more object

[.lead]
`HashMap` and `HashSet` wrap each entry in a `HashMap$Node`.

* A node is 24 B with compact headers, 32 B without.
* `HashSet` is a `HashMap` inside: 32.4 MB before counting the `Integer`s.
* EC `UnifiedSet` keeps the elements in its table: 8.4 MB, 4x less.
* Node plus box: about 48 B of heap per element to hold one `int`.

[.notes]
--
1,000,000 elements, compact headers on, "structure only" rows (the `Integer`s subtracted).
`HashSet` 32.4 MB ≈ 1,000,000 nodes × 24 B + 2^21 table slots × 4 B (derived).
`HashMap` structure 32.4 MB against `UnifiedMap` 16.8 MB, which stores key and value side by side in one array.
--
